# ABU-SSO — Unified Single Sign-On & Digital Campus Wallet

A unified authentication and campus services platform for Ahmadu Bello University. One login grants access to multiple campus services (Portal, LMS, Library, Hostel, Wi-Fi) plus a digital wallet with QR ID card.

## Tech Stack

- **Backend:** FastAPI (Python 3.12)
- **Templating:** Jinja2
- **Database:** SQLite (development) → PostgreSQL (production)
- **Auth:** JWT + bcrypt
- **Testing:** pytest + httpx
- **Docs:** Auto-generated Swagger (OpenAPI)
- **Deployment:** Render / Railway
